# Safe and authorized use

1. Scan only systems you own or have explicit written permission to assess.
2. Confirm scope, permitted test windows, request limits, and excluded paths before testing.
3. Keep conservative page, depth, timeout, and concurrency limits.
4. Do not expose the local dashboard publicly without authentication, TLS, access controls, and deployment hardening.
5. Treat reports as sensitive; they may contain hostnames and security observations.
6. Validate findings manually and coordinate remediation with the system owner.

VulnX is a low-impact configuration review aid. It is not an exploit framework and cannot prove that a system is secure.
